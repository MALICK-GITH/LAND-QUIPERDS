# Prompt pour générer le logo SKILL2CASH

## Prompt principal (Midjourney/DALL-E/Stable Diffusion)

```
Professional esports logo for "SKILL2CASH" - a competitive eFootball 1v1 gaming platform with real money stakes. 

Design elements:
- Bold, modern typography with "SKILL2CASH" text
- Dynamic gaming aesthetic with football/soccer elements
- Purple and violet color scheme (#8b5cf6 as primary)
- Minimalist but impactful design
- Shield or trophy shape suggesting competition and victory
- Subtle money/currency elements (coins, FCFA symbol) integrated tastefully
- Futuristic, tech-forward gaming vibe
- Clean lines, suitable for app icons and social media

Style references:
- Professional esports team logos
- Modern gaming app icons
- Fintech meets gaming aesthetics
- Bold, memorable, scalable

Color palette:
- Primary: Purple/Violet (#8b5cf6)
- Secondary: Dark background (#0a0a0a)
- Accent: Gold/Orange for money elements
- White/light for text contrast

Technical requirements:
- Vector-friendly design
- Works at small sizes (app icon)
- High contrast for visibility
- No complex gradients that won't scale well
- Centered, balanced composition
```
